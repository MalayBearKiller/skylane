# Skylane

브라우저에서 바로 하는 미니멀 항공 관제 게임. 빌드도, 의존성도 없이 `index.html` 하나로 돌아갑니다.

**▶ 플레이: https://malaybearkiller.github.io/skylane/**

## 실행

```bash
open index.html
```

또는 아무 정적 서버로 띄워도 됩니다 (`python3 -m http.server`).

## 플레이

1. 비행기에서 **드래그**해 비행 경로를 그립니다. 다시 그리면 덮어씁니다.
2. **같은 색** 활주로에 **끝단에서 방향을 맞춰** 진입하면 착륙합니다. 맞는 경로면 활주로가 빛나고 중심선에 자동 정렬됩니다.
3. 항공기끼리 **충돌**하거나 **연료**(비행기 주위 링)가 바닥나면 게임 오버.
4. 착륙이 쌓이면 업그레이드를 고릅니다: 새 활주로, 활주로 연장, 연료 보급, 흐름 제어, 감속.

| 키 | 동작 |
| --- | --- |
| `Space` | 일시정지 |
| `F` | 2배속 |
| `M` | 소리 켜기/끄기 |

마우스와 터치 모두 지원합니다. 효과음은 Web Audio로 실시간 합성합니다.
